# 运行与网络约定

## 模式

- `DEMO_MODE=true`：本地确定性演示，不联网、不收费。
- `DEMO_MODE=false`：连接 `API_BASE_URL` 指向的星幕可信后端。
- 生产默认必须是 HTTPS，不能在代码中提供忽略证书校验的能力。

## 本地后端

- Android 模拟器：`http://10.0.2.2:<port>/v1`，仅 debug 变体允许明文。
- Android 真机：使用真机可达的开发机局域网地址或 `adb reverse` 对应地址。
- OpenHarmony 真机/模拟器：使用设备可达的局域网地址或明确配置的调试映射；先验证网络可达。

## 恢复

前台进度页可保持 SSE；进入后台时关闭长连接。恢复时先 GET 运行聚合状态，再携带 `Last-Event-ID` 连接 SSE。网络失败采用有限指数退避，不创建新的幂等键重放同一用户意图。
