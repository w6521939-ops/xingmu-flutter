# 星幕 AI 漫剧手机客户端 MVP

## 1. 产品目标

让用户在 Android 或 OpenHarmony 手机上输入一个主题或故事，审核 AI 生成的剧本与视觉设定，启动镜头视频生成，并最终预览、下载和分享一段完整 MP4 漫剧。

实现状态说明：当前仓库交付的是第一阶段手机客户端——演示闭环、领域状态机、REST 客户端、生成控制与双端构建。下文关于手机登录、SSE、真实播放、下载和系统分享的条目仍是第二阶段验收目标，不能作为当前版本已完成能力对外宣传。

MVP 的核心价值是“可靠地管理一次云端漫剧生成”，不是在手机上训练/运行视频模型，也不是提供专业非线性剪辑器。

## 2. 目标用户与主要场景

- 短视频创作者：用主题快速生成 30～90 秒竖屏故事。
- 漫剧工作室成员：在移动端查看任务、审核镜头和重试失败项。
- 项目展示者：使用不联网的演示模式体验完整产品流程。

## 3. P0 功能需求

### FR-01 演示与连接模式

- 首次启动可进入演示模式，不要求 API Key。
- 演示数据必须明确标记，不上传内容、不产生费用。
- 真实模式只配置星幕后端地址和用户身份，不输入百炼/Wan2.2 密钥。

### FR-02 项目管理

- 展示项目列表的加载、空、错误和离线状态。
- 新建项目时填写名称、描述和画幅比例。
- 支持查看、重命名和软删除项目。
- 并发修改冲突时提示用户刷新，不静默覆盖。

### FR-03 剧本生成

- 接受主题、故事梗概或已有剧本文本。
- 创建异步 Script Job，展示排队、生成进度、失败原因和完成结果。
- 结果至少包含标题、故事梗概、风格规则、角色、场景、道具、分集与镜头。
- 用户确认剧本后才能创建生成计划。

### FR-04 角色与场景连续性

- 展示角色卡、场景卡、道具卡及其稳定描述。
- 每个实体使用稳定 ID；用户可选择参考图。
- 镜头引用按固定实体顺序提交，避免角色漂移。
- 单镜头支持审核、驳回和重生成。

### FR-05 生成计划与预算

- 创建计划前展示镜头数量、模型策略和费用区间。
- 用户设置项目硬预算；预计超过可用预算时禁止启动。
- 默认 Provider 为百炼，可选择服务端已启用的 Wan2.2 或自动策略。
- 计划启动后保留不可变快照；修改内容需创建新计划或新修订。

### FR-06 运行与任务队列

- 展示整次运行和各阶段子任务进度。
- 支持暂停、恢复、取消整次运行，以及重试/取消单个失败任务。
- 重复点击或网络重试不得创建重复收费任务。
- App 退到后台或被系统回收后，重新进入仍可恢复服务端状态。

### FR-07 实时状态

- 前台使用 SSE 接收任务、预算和导出事件。
- 网络断开时展示离线状态并进行有限退避重连。
- SSE 重连后通过 REST 重新校准，不遗漏最终状态。

### FR-08 成片导出

- 使用完成的镜头、配音、字幕和音乐创建 MP4 导出。
- 展示排队、合成、失败、完成状态。
- 完成后可在线播放、下载到系统目录并调用系统分享。
- 下载地址过期时自动向后端换取新票据，不能长期保存签名 URL。

### FR-09 错误与降级

- 区分离线、登录过期、预算不足、供应商限流、内容安全拒绝、输入错误和服务端故障。
- 可重试错误提供明确重试入口；不可重试错误提供修改输入或联系支持的路径。
- 快速重复点击、长文本、小屏、深色模式、横竖屏和系统返回均不得造成崩溃或重复提交。

## 4. 非功能需求

### 安全

- 客户端和仓库中不得出现供应商 API Key、对象存储永久密钥或签名私钥。
- 生产流量必须使用 HTTPS；访问令牌不得放在 URL 或日志中。
- 上传前提示内容将发送到云端处理；删除项目具有明确的数据保留说明。

### 可靠性

- 所有收费/生成/导出 POST 使用幂等键。
- 所有覆盖和状态迁移使用 ETag/If-Match。
- 服务端任务状态是权威来源，本地缓存仅用于加速展示。

### 性能

- 首页已有缓存时应立即显示骨架或缓存，不等待生成服务。
- 长列表分页加载；缩略图按显示尺寸请求并缓存。
- SSE 只在需要实时进度的前台页面保持，后台依靠恢复查询。

### 可访问性与适配

- 支持系统字体放大、屏幕阅读标签、44dp 以上主要触控区域和高对比状态。
- 关键状态不能只用颜色表达。
- 适配 Android 与 OpenHarmony `default` 设备类型的安全区、返回键和横竖屏。

## 5. 明确不在 MVP 内

- 手机端运行文生图/图生视频大模型。
- 模型训练、LoRA 训练或权重下载管理。
- 多轨专业时间轴、逐帧特效和桌面级调色。
- 账户充值、支付、订阅或模型市场。
- 公开社区、素材交易和多人实时协作。
- 把演示动画或占位视频宣称为真实 AI 生成结果。

## 6. 验收标准

### 客户端演示闭环

1. Android 和 OpenHarmony 均能打开演示模式。
2. 用户可完成“新建项目 → 生成剧本 → 审核卡片 → 创建计划 → 查看队列 → 导出完成 → 预览成片”的确定性演示流程。
3. 演示流程不联网、不要求密钥、不产生收费请求，并始终显示“演示模式”。

### 真实后端闭环

1. 使用测试账号从主题创建结构化剧本。
2. 至少一个镜头完成首尾帧视频生成和配音。
3. 后端成功合成并提供可播放的 MP4。
4. 暂停/恢复、单任务重试、SSE 断线恢复和预算拦截均有测试证据。
5. Android release 与 OpenHarmony release 配置不允许明文 HTTP，安装包不含供应商密钥。

### 工程验收

- `flutter analyze`：必须 `passed`。
- `flutter test`：必须 `passed`。
- `flutter build apk --debug`：必须 `passed`。
- `flutter build hap --debug`：必须 `passed`。
- Android 真机或模拟器运行：发布前必须 `passed`。
- OpenHarmony API 20 真机或模拟器运行：发布前必须 `passed`。

未实际执行的命令只能报告为 `not run`，失败命令必须报告为 `failed`。
